# Дуга — бриф проекта

Источник: документ «Дуга: запросы для кодера», запрос 0. Прототип: `duga.html` в корне.

Мы делаем веб-приложение «Дуга» — экранную клавиатуру
для набора одним правым большим пальцем. Цель: ссылка,
которую я отправляю друзьям. Они открывают её на телефоне,
пробуют печатать и сравнивают с обычной клавиатурой.
Приложение должно быть удобным и красивым.

Идея раскладки. Прикладываю прототип duga.html: поведение и
геометрию бери оттуда, код можно переписать.
- Клавиши — секторы колец вокруг точки опоры большого
  пальца в правом нижнем углу экрана.
- Ближние к углу кольца: ⇧, смена языка, ⌫, пробел, ⏎.
- Два средних кольца — зона, куда палец достаёт без напряжения.
  Там самые частые буквы, самые частые из них — по диагонали
  (около 135°). Редкие буквы и знаки — во внешних кольцах.
- Зона нажатия — весь сектор, без мёртвых зон между клавишами.
- Языки: русский и английский.

Ограничения:
- Это веб-демо: печатаем внутри страницы. Системной клавиатурой
  телефона оно не станет, это отдельный проект на потом.
- Без сервера и аккаунтов. Всё хранится в localStorage.
- Стек: Vite + TypeScript, без тяжёлых фреймворков. Клавиатура
  рисуется в SVG (или Canvas, если SVG не держит 60 кадров в секунду).
  Хостинг: GitHub Pages через GitHub Actions.
- Качество: клавиша подсвечивается в том же кадре, что касание;
  60 кадров в секунду на среднем Android; никакого зума, прокрутки
  и выделения текста при наборе; работает в Safari iOS 16+ и Chrome Android.

Как работаем:
- По этапам, я присылаю их по одному. Не добавляй ничего сверх
  этапа, даже если кажется полезным: запиши идею в IDEAS.md.
- Раскладки — данные в отдельном файле. Геометрия — отдельный
  модуль с юнит-тестами. Обработка касаний — отдельный модуль.
- Все пороги (время удержания, длина смаха и т. п.) — в одном
  файле config.ts, чтобы их легко было подстраивать.
- После каждого этапа: коммит, ссылка на превью и короткий
  список, что проверить на телефоне.
- Я не программист. Объясняй решения простыми словами, а когда
  есть выбор, предлагай варианты и свой совет.

Объём: для показа друзьям хватит этапов 0–4. Дальше — только по явному решению.

## Для кого (решение от 2026-10-20)

Бесплатный продукт, без монетизации. Две группы:
- люди, у которых нет одной руки или она не работает: для них набор одной рукой — необходимость;
- те, кто печатает одной рукой по ситуации: во второй руке что-то держат.

Эталон для сравнения — Яндекс Клавиатура со свайпом (ей пользуется автор). Дуга должна быть не хуже её по удобству свайпа.
Следствия: нужен режим для левой руки (зеркальная дуга), крупные цели и терпимость к неточным касаниям,
никакие данные не покидают телефон.
