# Дуга

Бесплатная экранная клавиатура для набора одной рукой. Клавиши — секторы колец вокруг точки опоры
большого пальца в нижнем углу экрана, для правой или левой руки. Для тех, у кого нет одной руки,
и для тех, кто печатает одной рукой, потому что во второй что-то держит.

**Попробовать:** https://danyapole.github.io/duga/ (открой на телефоне).

Это веб-демо: печатать можно внутри страницы. Всё работает на телефоне, текст никуда не отправляется.

- Раскладки: «Слоги» (гласные в ближнем кольце, частые сочетания рядом) и ЙЦУКЕН / QWERTY для сравнения.
- Способы ввода: Свайп, Флик, Микс, Луч, Пульс — см. [MODES.md](MODES.md).
- Тест для людей: при первом заходе или кнопкой «Тест». 5–8 минут, в конце результат можно отправить автору.
- Русский и английский.

## Запустить у себя

```bash
node tools/serve.js
```

Открой http://localhost:5173. Сайт на GitHub Pages собирается сам при каждом пуше в `main`
(`.github/workflows/pages.yml` → `tools/build-pages.js`).

## Инструменты

- `tools/swipe-test.js` — проверка точности свайп-ввода на имитации.
- `tools/layout-opt/` — подбор раскладки и флик-клеток по частотам букв и слов.

Лицензии сторонних данных — в [THIRD_PARTY.md](THIRD_PARTY.md).
